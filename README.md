# gakujin-mori-app

神山まるごと高専 基礎数学Ⅰ 後期第1回（三角比導入） — 「岳人の森」フィールドワーク用アプリのプロトタイプ

> 仕様の全体像: [full-spec.md](./full-spec.md)

## 現在のステータス：モック（プロトタイプ）

**このバージョンは「授業の流れを確認するためのモック」です。** クラス全員の測定データを
リアルタイムで共有する本番用データベースはまだ実装していません。

- データはすべて**端末内のlocalStorageのみ**に保存される（他の生徒の端末とは共有されない）
- MAP画面には自分の記録に加えて「デモ用の見本データ（DEMO班）」が重ねて表示される（トグルでON/OFF可）
- 写真・GPS・距離・角度・目線の高さの入力、tanアンロック、高さ計算、三角形の図解表示は**すべて実際に動作する**

### 本番化（クラス全員でMAPを共有する）に必要な作業

1. 共有DBの導入（Supabase推奨：無料枠・Postgres・Storageが揃っている）
2. `src/storage.js` のlocalStorage読み書きをDB呼び出しに置き換え
3. `src/App.jsx` のMAP用データ取得をポーリング or リアルタイム購読に変更
4. 写真は圧縮後dataURLではなくSupabase Storageにアップロードしてurlを保存
5. 現地の電波状況が悪い前提で、送信失敗時にlocalStorageへキューイング→復帰後に同期するオフライン対応（仕様書 37章）

## 画面構成

| 画面 | 内容 |
|------|------|
| オンボーディング | 班名・目線の高さを入力 |
| ホーム | 新しく測る／MAP／記録／今日のミッション／振り返り への導線 |
| 新しく測る | 対象物名・カテゴリー・写真・GPS・距離・角度を記録（高さは計算しない） |
| Discovery詳細 | 未解放時は「？？？」のみ表示。解放後にtan計算→結果と三角形の図解 |
| MAP | Leaflet地図上に自分の記録＋デモ見本データのピンを表示 |
| 記録一覧 | 自分の班のDiscovery一覧 |
| 振り返り | 授業終了時の自由記述（200字） |

数学解放コード（デフォルト `4832`）はトップバーの🔒ボタン、またはDiscovery詳細の
「🔓 数学を解放して計算する」から入力できる。
